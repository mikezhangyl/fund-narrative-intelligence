# Multi-Match Precision Flags Execution Plan

## Purpose

Treat multi-match fallback mappings as useful but lower-confidence evidence that needs review.

## Scope

- Keep every fallback mapping generated by registry terms.
- Lower confidence for fallback mappings when one holding matches multiple narratives.
- Mark affected mappings with `needs_review`.
- Emit `mapping_precision_flags` in raw/scoring JSON and Markdown/HTML reports.

## Non-Goals

- Deleting ambiguous mappings automatically.
- Splitting mapping weight across narratives.
- Changing fixture-rule mappings.

## Acceptance

- Unit tests cover confidence reduction and review flags.
- Pipeline tests cover raw/scoring/report output.
- Real smoke still passes and calibrated stages remain stable.
- Full quality gates pass.
