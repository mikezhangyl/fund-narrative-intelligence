免费公开源优先的叙事数据策略

日期：2026-06-04；适用范围：FNI 与 stock-data-gateway 共享 Linear 项目的叙事数据源路线。

决策：当前阶段从“付费 provider 优先”调整为“免费公开源 / 官方源 / 低风险爬虫优先”。付费源不删除，但降为 Later，不再作为当前里程碑依赖。

边界不变

  • stock-data-gateway 负责外部采集、爬虫、官方 API、限速、缓存、robots/TOS、source-event 标准化。
  • FNI 负责产品需求、consumer contract、探针、来源质量展示、digest/report 和 review workflow。

为什么改

我们现在要证明的是：能不能稳定发现新的市场叙事线索，并把证据来源和可信度讲清楚。早期不需要复刻机构新闻终端。官方公开源和低风险公开源已经足够支撑 Can-Do 阶段。

优先级

优先级来源类别例子负责方信任角色

Later付费终端/新闻分析Wind、Choice、iFinD、Reuters、RavenPack、AlphaSensePM/vendor evaluation未来可选 fallback

Linear 新建方向

共享 milestone：M20 - Open Narrative Source Gateway Capability。

Gateway-owned stories 会使用 [GATEWAY] 前缀；FNI-owned follow-up 会使用 [FNI] 前缀，避免 Developer 混淆责任边界。

验收口径

  • Gateway 至少打通一个官方 trusted fact 源和一个 context/heat 源。
  • 每条 source event 都带 source URL、发布时间、抓取时间、hash、license/retention、trust tier、source quality、degradation events。
  • FNI 只通过 gateway contract 消费，不新增直接外部采集。
  • FNI source quality dashboard 能显示每个 gateway source kind 的覆盖状态。
  • Fresh narrative digest 能显示候选叙事、证据链接、可信度和降级原因。
非目标：当前阶段不做付费源集成、不做验证码绕过、不做 stealth browser、不做住宅代理、不抓登录/付费内容、不把社区发言当事实。
