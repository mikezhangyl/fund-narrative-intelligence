Round 4 Durable Storage Migration Readiness 验收说明

Linear: MIK-96 + MIK-91 · 日期: 2026-05-30

能力目标

本切片不直接切换 SQLite/Postgres，而是把 Narrative Service 从 JSON ledgers 迁移到 durable store 所需的 schema、迁移阶段和 contract invariants 明确化，并通过服务接口和 conformance contract 固化。JSON mode 在 parity 通过前仍然可用。

服务入口

入口用途
GET /api/v1/narratives/storage/migration-plan返回 current store、目标 adapter、实体清单、append-only/idempotency 规则、迁移阶段和 parity check endpoints。

实体范围

实体写入模型说明
narrativestrusted read model可信叙事 registry。
stock_narrative_mappingstrusted read model股票到叙事映射。
evidence_packstrusted read model映射证据包。
source_eventsappend only来源事件 ledger。
candidate_narrativesderived read model候选叙事读模型。
review_actionsappend only人工 review action ledger。
promotion_decisionsappend onlytrust promotion decision ledger。
radar_source_signalsappend onlyRadar source signal ledger。
radar_snapshotsappend only窗口化 radar scoring snapshot。
job_runsappend onlyoperational job run ledger。

迁移不变量

  • HTTP contract 不允许因存储 adapter 变化而破坏。
  • Append-only semantics 必须保留。
  • JSON mode 在 SQLite parity 通过前保持 fallback。
  • Trusted promotion write path 仍然只能是 promotion commit。

验证

新增服务测试先以 404 失败确认 RED，再实现后通过：uv run pytest services/stock-narrative-service/tests/test_http_service.py -q -k 'storage_migration_plan'。

Conformance contract 验证：uv run pytest tests/test_narrative_service_conformance_probe.py -q -k 'append_only_ledger_policy'。
