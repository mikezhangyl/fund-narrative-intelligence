Narrative Radar Bubble API 契约

日期：2026-05-29

覆盖 Linear：MIK-74、MIK-84

服务接口

Narrative Service 现在提供 GET /api/v1/narratives/radar/bubbles。该接口返回 service-owned、library-agnostic JSON，前端可以直接绘制 bubble chart，FNI 不需要重新计算 heat、trend、market confirmation 或 evidence quality。

Bubble Row 字段

字段用途
heat_score气泡大小。
trend_accelerationX 轴位置。
market_confirmation_scoreY 轴位置。
momentum_state颜色。
trust_status边框或标记。
evidence_quality_score证据质量标记。
evidence_refs / sparkline_points / score_componentstooltip 和 drill-down 入口。

Visualization Contract

响应包含 visualization_contract.version=bubble-chart-contract-v1，并明确 size、x、y、color、border、marker 和 tooltip 字段映射。该契约不绑定任何前端图表库。

降级输入

当没有可用 source signals 时，接口返回空 bubble list，并包含 RADAR_BUBBLES_EMPTY product-data-gap warning；契约元数据仍然返回，避免 silent success。
