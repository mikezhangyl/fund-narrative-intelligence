Round 4 Review Workflow 状态机验收说明

Linear: MIK-97 + MIK-92 · 日期: 2026-05-30

能力目标

本切片把候选叙事从 evidence drill-down、人工 review action、promotion preflight 到 trusted promotion commit 的路径整理成服务拥有的状态机。review action 和 preflight 都不会写 trusted record；只有 promotion commit 在所有 gate 通过后写入可信 registry、mapping、evidence pack 和 promotion decision ledger。

服务入口

入口用途
GET /api/v1/narratives/review-workflow/contract返回状态机、guardrail、transition 和审计字段。
GET /api/v1/narratives/review-workflow返回每个 candidate 的当前 workflow state、preflight 状态、最新 review action 和 promotion decision。
GET /narratives/review返回操作员 HTML 页面，用于查看 pending、blocked、ready、deferred、rejected、trusted 路径。

状态模型

状态含义
candidate_untrusted候选输入的信任起点；不能直接进入可信 registry。
pending_review等待人工 approve、reject 或 defer。
approved_blocked_by_evidence已 approve，但 source evidence、rationale、exclusion 等 gate 不完整。
ready_for_trust_auditreview 和 evidence gates 已通过，可进入 trust audit。
trusted_validatedpromotion commit 成功，可信记录已原子写入。
rejected人工拒绝，不进入 promotion。
deferred人工延期，需要下一轮来源或上下文。
deprecated预留给后续可信叙事下线流程。

关键约束

  • Intake 只创建 candidate_untrusted 记录。
  • Review action 只允许 approve、reject、defer，不能直接 promotion。
  • Promotion preflight 是 non-mutating。
  • Promotion commit 是唯一 trusted-record write path。
  • Failed promotion 不写 trusted records。
