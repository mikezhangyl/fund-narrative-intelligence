Round 4 Operational Scheduling 验收说明

Linear: MIK-95 + MIK-90 · 日期: 2026-05-30

能力目标

本切片把 Narrative Service 的重复性操作抽象为 job definition 和 append-only run ledger。操作员可以查看可运行任务，手动触发本地验证，并在 run ledger 中看到每次运行的状态、时间、耗时、warnings、artifact links 和 error category。

服务入口

入口用途
GET /api/v1/narratives/jobs/contract返回 job definition、run ledger、状态枚举和写保护规则。
GET /api/v1/narratives/jobs/definitions返回默认或配置文件中的 job definitions。
POST /api/v1/narratives/jobs/run手动触发一个 job，并追加 run ledger 记录；支持 idempotency key。
GET /api/v1/narratives/jobs/runs返回 run ledger，可按 job id 或 status 过滤。

默认 Job

Job类型写入边界
live-provider-smokelive_provider_smokediagnostic only；提示运行 live validation dashboard。
source-intakesource_intakedry-run by default；不写 trusted store。
narrative-radar-scoringradar_scoring读取 radar preview；生成 read-only snapshot artifact link。
report-pack-generationreport_pack_generationartifact-only；报告生成仍由 FNI artifact command 执行。

运行账本

每条 run record 包含 JR_* run id、job id、triggered_by、started_at、finished_at、status、duration_ms、warnings、artifacts、error_category、idempotency_key、timeout、concurrency guard、retry policy 和 trusted_store_mutation=none。
