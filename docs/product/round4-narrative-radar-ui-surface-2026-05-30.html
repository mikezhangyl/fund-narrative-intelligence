Round 4 Narrative Radar UI 验收说明

Linear: MIK-94 + MIK-89 · 日期: 2026-05-30

能力目标

本切片把 Narrative Radar 从纯 API payload 推进到服务自带的操作员 UI。页面由 Narrative Service 提供，直接消费 service-owned radar bubbles、detail link 和 visual mapping contract，不在 UI 或 FNI 层重新计算 heat、trend、market confirmation 或 trust 状态。

服务入口

入口用途
GET /api/v1/narratives/radar/ui-contract返回 UI 边界、数据端点、稳定标识、状态模型和 visual mapping。
GET /narratives/radar返回 Narrative Radar HTML 页面，展示 bubble map、legend、empty/degraded diagnostics 和 drill-down 链接。

边界决策

  • Narrative Service API 是 score authority。
  • UI 只负责 rendering、filters、interactions 和 drill-down navigation。
  • Score recalculation 在 UI 中明确 forbidden。
  • FNI 后续可以链接 Radar，但不能计算 radar data。
