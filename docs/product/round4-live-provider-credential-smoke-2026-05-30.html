Round 4 实时凭证 Smoke 验收说明

Linear: MIK-93 + MIK-88 · 日期: 2026-05-30

能力目标

本切片把 Round 2 的实时验证看板升级为 Round 4 的 credential-safe smoke surface。操作员可以在运行雷达评分、报告包或调度任务前，先看到 gateway、Tushare 权限路径和 Narrative Service 是否已配置、可访问、超时、降级、权限受限或成功。

状态口径

状态含义操作影响
configured本地边界配置存在，未返回 secret 值。继续执行 endpoint smoke。
not_configured本地 gateway 或 service URL 缺失。提示配置下一步，不让整次 smoke 崩溃。
reachable服务可连通，但未评估业务契约。需要补业务探针。
provider_permission_requiredprovider、quota、权限或认证不足。归属到 gateway 或 owning service 处理。
request_timeout请求在限定时间内超时。记录超时诊断和下一步，不阻断其他检查。
upstream_degraded上游返回降级状态或 warnings。保留部分成功信息和降级原因。
schema_mismatch响应结构或业务数据不符合 smoke 契约。需要对齐服务契约。
contract_failedHTTP/JSON 契约失败。必须修 owning service 后再依赖下游任务。
success返回可用业务数据。无额外动作。

输出契约

每一行 smoke check 都包含 id、owner_service、endpoint、required_credential_hint、status、latency_ms、warnings、failure_reason 和 next_action。输出只允许出现环境变量名和凭证提示，不允许出现 token、API key 或 secret 值。

验证产物

确定性 fixture 产物位于 outputs/live_validation_dashboard/2026-05-30-mik-93-88-fixture/，包含 JSON 和中文 HTML。该 fixture 在未配置 live URL 的情况下返回 completed_with_actions，证明缺少配置是操作状态，不是工具崩溃。

边界

FNI 仍只调用本地 gateway 或 Narrative Service HTTP 边界，不直接访问 Tushare、AkShare、EastMoney、新闻网站、浏览器自动化、代理或反爬基础设施。真实 provider 权限由 gateway/service 归属处理。
