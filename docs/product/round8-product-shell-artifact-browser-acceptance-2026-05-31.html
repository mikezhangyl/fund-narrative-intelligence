Round 8 产品壳与产物浏览器验收

本轮先完成 MIK-165 / MIK-166 的实物合同，再完成 MIK-161 / MIK-162 的本地产品首页和产物浏览器。

交付范围

  • product-shell-route-registry-v1：声明页面、owner service、数据来源类型、新鲜度/降级标签和产品壳禁止逻辑。
  • product-shell-artifact-index-v1：扫描现有 outputs，生成安全的 JSON/HTML 路径、状态、run id、source mode、freshness 和 superseded 标记。
  • product-shell-v1：集成 route registry 和 artifact index，生成本地产品首页。
  • 产物浏览器中文 HTML：从一个页面查看 Round 5/6/7/8 已有 JSON/HTML 产物。

实物产物

  • outputs/product_shell/round8-current/route_registry.html
  • outputs/product_shell/round8-current/artifact_index.json

  • outputs/product_shell/round8-current/index.html
  • outputs/product_shell/round8-current/artifact_browser.html

验收证据

  • 测试：tests/test_product_shell.py 覆盖 route registry、artifact index、首页、artifact browser 和 CLI 输出。
  • 命令：uv run python scripts/build_product_shell.py --artifact-root outputs --output-dir outputs/product_shell/round8-current
  • 本地实物索引结果：468 个 JSON 产物，62 个 HTML 链接。

边界声明

产品壳只做导航、索引和展示，不在页面内重算雷达热度、叙事质量分、组合暴露指标，也不直接访问 provider。
