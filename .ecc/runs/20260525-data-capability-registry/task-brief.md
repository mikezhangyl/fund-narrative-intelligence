# Task Brief

Implement a machine-readable market-data capability registry that records:

- which datasets each analysis capability requires,
- current acquisition status and difficulty,
- primary/fallback source ownership,
- local gateway readiness,
- known risk and cache implications,
- and live validation linkage.

The goal is to move data-source work from ad hoc provider additions to a
controlled capability ledger that can be read by scanners, validation scripts,
reports, and the future local data gateway integration.
